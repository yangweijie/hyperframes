## ffmpeg layer-render 工作流打通（2026-08-17）

- 用 `packages/ffmpeg-layer-renderer`（最新提交 9d259eb 新增，README 承诺 `npx hyperframes layer-render`，但 CLI 未注册命令）。
- **改动 1**：在 `packages/cli` 新增 `src/commands/layer-render.ts` 并注册到 `cli.ts` commandLoaders；cli 的 package.json 加 `@hyperframes/ffmpeg-layer-renderer: workspace:*`（bun install 已链接到 `packages/cli/node_modules/@hyperframes/`）；tsup build 把该包 **bundle** 进 `dist/cli.js`（改包源码后必须 `cd packages/cli && npx tsup --no-clean` 重建，普通 tsup 触发 CodeBuddy safe-delete 拦截，需用 `--no-clean`）。
- **改动 2**：修复 `compose.ts` overlay 滤镜 `format=yuva420` → 先误改 `yuva420p`（overlay 的 format 枚举不支持带 p 平面格式，报 "Undefined constant"），最终改为 `format=auto` 才正确保留 alpha。scale 滤镜的 `format=yuva420p` 是对的（scale 支持平面格式）。
- **改动 3**：`render.ts` 的 `ensureGsapAsset()` —— 包不打包 gsap，materialize 注入相对 `gsap.min.js`，预渲染浏览器 404 导致 timeline 未注册。`ensureGsapAsset` 从 `node_modules/.bun/gsap@*/node_modules/gsap/dist/gsap.min.js` 向上遍历找到并 copy 到 projectDir，子组件动画才生效。
- **改动 4**：`LayerRenderResult`（types.ts）扩展 `layers`/`scaleMode` 字段，`renderLayerComposition` 返回填充，供 CLI 报告。
- **环境必须**：
  - `core` 包需先 `bun run build`（生成 `packages/core/dist/hyperframe.manifest.json`），否则预渲染报 "Missing manifest"。
  - 浏览器：hyperframes 缓存的 chrome-headless-shell 在本机启动失败（0xC000007B，缺运行库）；改用系统 **Edge** `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe` 作为 headless shell，通过 **`PRODUCER_HEADLESS_SHELL_PATH`** 环境变量注入（engine 的 resolveHeadlessShellPath 读此变量）；msedge 可正常 headless 启动。
  - 运行前需设：`$env:PRODUCER_HYPERFRAME_MANIFEST_PATH = packages/core/dist/hyperframe.manifest.json`（producer 的 hyperframeRuntimeLoader 首选此变量，否则 cwd 解析失败）。
- **子组件写法**：必须像 `packages/producer/tests/vignelli-stacking`——子组件文件是 `<template id="x-template">` 片段（根 div 带 `data-duration`），主 index.html 用 `<template data-composition-src="./compositions/x.html">` 引用；完整 HTML 文档形式的子组件会因缺 data-duration + gsap 未注册而零时长失败。
- 产物：`d:\git\web\hyperframes\product-launch\` 目录（index.html + compositions/overlays.html + compositions/captions.html），`npx hyperframes layer-render index.html -o out.mp4 --fps 30` 成功生成 `out.mp4`（1080x1920@30fps，3 层：1 背景 + 2 透明 overlay，prerender 81712ms + composite 2522ms）。
- 注意：`PRODUCER_HEADLESS_SHELL_PATH`/`PRODUCER_HYPERFRAME_MANIFEST_PATH` 两步环境变量因属环境 workaround 未写进包代码，每次新 shell 需重设。
